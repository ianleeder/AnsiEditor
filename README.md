# (Ian's super-sexy) ASCII ANSI Editor

I wrote this around 2006, before GitHub was created. And before I understood version control. I dug up the source code recently so I could upload it to GitHub.

This is a tool to read (and write) maps from the BBS game MajorMud. I needed to decode the map files (see [assets/maps](/assets/maps/)) that came with the game. From memory there was no complicated file format, it was simply a difficult (for WinXP era) file encoding, and understanding how to apply the ANSI colour codes.
